1 · Know the parent functions

A parent function is the simplest example of a family. Its graph is the starting point for transformations.

2 · The general transformation rule

y = a · f(b(x − h)) + k
a · Vertical scale / reflection|a| > 1: stretch; 0 < |a| < 1: shrink. Negative a: reflect over the x-axis.
b · Horizontal scale / reflectionUse the reciprocal 1/|b|. Negative b: reflect over the y-axis.
h · Horizontal translationf(x − h) shifts right h; f(x + h) shifts left h (for positive h).
k · Vertical translation+k shifts up; −k shifts down (for positive k).

Translation quick reference

FormMeaning
f(x) + 4Vertical translation up 4
f(x) − 4Vertical translation down 4
f(x − 4)Horizontal translation right 4
f(x + 4)Horizontal translation left 4

Reflections

−f(x) reflects across the x-axis. f(−x) reflects across the y-axis. A negative sign outside changes the output; inside changes the input.

Vertical versus horizontal scaling

ExampleTransformation
y = 3x²Vertical stretch by 3
y = 0.4x²Vertical shrink by 0.4
y = (2x)³Horizontal shrink by 1/2
y = (0.2x)³Horizontal stretch by 5

Why the reciprocal? In f(2x), you only need half the original x-value to get the same input to f. That makes the graph half as wide.

3 · Worked examples and important ideas

Example A: Multiple transformations

y = −2|x + 4| + 1
  1. Family: absolute value.
  2. Shift left 4.
  3. Reflect across the x-axis.
  4. Vertical stretch by 2.
  5. Shift up 1.

The vertex moves from (0, 0) to (−4, 1).

Example B: Writing an equation

Start with the quadratic parent function. Shift left 2, vertically stretch by 2, then shift down 4.

y = x² → (x + 2)² → 2(x + 2)² → 2(x + 2)² − 4

Example C: Equivalent descriptions

(2x)³ = 8x³. This is either a horizontal shrink by 1/2 or a vertical stretch by 8. Both describe the same graph.

Example D: Does order matter?

Horizontal shift and vertical stretch can be done in either order: both give 3(x − 4)². But vertical shift and vertical stretch generally do not commute:

Stretch by 3, then up 4y = 3x² + 4
Up 4, then stretch by 3y = 3(x² + 4) = 3x² + 12
